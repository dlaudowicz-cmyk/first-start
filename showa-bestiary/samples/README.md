# Samples — Generated Archive Pages

Proof-of-concept artwork generated from the [prompt pack](../production/prompt-pack.md) to
validate the visual system. Images live in the generation workspace; links below point to the
rendered assets (download into the repo is blocked by this environment's network policy, so
they are referenced by URL rather than committed as binaries).

> **Reminder:** treat generated output as the *painted plate*. Kanji / ID / stamps / metadata
> should be re-set as vetted vector overlays for final production — AI text rendering is
> unreliable, so always verify the Japanese before printing.

Model: `nano_banana_pro` · aspect `2:3` · 1k · 2 credits each.

## Production notes / next iteration

- **Verify all kanji** with a fluent reviewer; re-set as vector overlays where the model
  malformed strokes (especially multi-glyph titles like 天空王).
- Push **grain + misregistration** heavier for a truer screenprint feel.
- Lock the **bottom-third title band** so overlay typography always has clean space.
- For print: upscale to ≥300dpi at A3/A2 and composite the archive layer (stamps, metadata,
  exact kanji) on top of the painted plate.
