# Marketing — Etsy Listing Pack (Collection 01: Beasts)

Ready-to-paste Etsy listings for the 10 launch Beasts, built from
[`../catalog/creatures.json`](../catalog/creatures.json). Each follows Etsy SEO best practice:
keyword-front-loaded title (≤140 chars), all 13 tags used (≤20 chars each), a benefit + lore
description, and variation guidance. A reusable template is at the end for the other 20 creatures.

**Global setup for every listing**
- **Variations:** Size = A4 / A3 / A2 (or A4/A3/Poster). Optionally Frame = Unframed/Framed.
- **Category:** Prints → Giclée / Digital Prints. **Type:** Physical (POD) — and a mirrored
  Digital listing where useful.
- **Photos (all 10 slots):** framed mockup · in-room scene · texture/grain macro · stamp+ID
  closeup · size chart · collection flatlay · packaging. Add a slow-pan video on hero items.
- **Materials:** matte/giclée archival paper, fade-resistant inks.
- **Always end the description with the in-universe warning + a link to your Shop/Gumroad.**
