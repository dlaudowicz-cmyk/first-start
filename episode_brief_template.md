# Episode Brief Template

Ein vollständiges Brief-Sheet für jede einzelne Folge. Ohne ausgefüllten
Brief wird nicht gedreht, nicht geschnitten, nicht gepostet.

Das Brief lebt als Markdown-Datei pro Folge im Verzeichnis
`/episodes/YYYY-MM-DD_NN_<slug>.md` (oder als Notion/Airtable-Record).

---

## Template (zum Kopieren)

```markdown
# Episode Brief №. {NN} — {Arbeitstitel}

**Status:** ☐ Idee  ☐ Brief  ☐ Skript  ☐ Dreh  ☐ Schnitt  ☐ QA  ☐ Live
**Slot:** {Datum · Plattform · Uhrzeit}
**Rubrik:** {Framing-Alarm | Der Satz, der dich lenken soll | Manipulation der Woche | Warum das so gut funktioniert | Mentalismus im Alltag | Anatomie einer Schlagzeile}
**Säule:** {Framing | Angst | Empörung | Autorität | Soziale Bewährtheit | Wiederholung | Identität | Kognition | Aufmerksamkeit | Medienpsychologie}
**Owner:** {Name}
**Last Reviewer:** {Name}

---

## 1. Thema

Eine Beobachtung in **einem** Satz, generisch, ohne Namen.

> Beispiel: „Die Floskel *'bedauerlich'* taucht regelmäßig in
> Pressestatements auf, nachdem Verantwortung im Raum steht."

---

## 2. Hook

Finale Hook (max. 12 Wörter, ein Satz, im selben Wortlaut, in dem sie
gesprochen wird):

> „{Hook}"

Alternativen, falls Variation getestet werden soll:

- Variante B: „{Hook B}"
- Variante C: „{Hook C}"

---

## 3. Mechanismus

Fachbegriff + alltagstaugliche Definition in zwei Sätzen.
Wenn nötig: Quelle (Lehrbuch/Übersichtsartikel).

- **Begriff:** {z. B. „Soft-Verb"}
- **Definition:** „{1–2 Sätze}"
- **Quelle/Hinweis:** {optional}

---

## 4. Beispiel

Ein konkretes, **anonymisiertes** oder strukturell formuliertes
Beispiel. Bei sensiblen Themen: zwei Beispiele aus unterschiedlichen
Feldern.

- **Beispiel 1 (Hauptbeispiel):** {generisch beschrieben}
- **Beispiel 2 (Streuung, anderes Feld):** {generisch beschrieben}
- **Beispiel 3 (optional Streuung):** {generisch beschrieben}

---

## 5. Neutrale Einordnung

Wie der Mechanismus eingeordnet wird, ohne Lager und ohne
Absolutheitsbehauptung. Zwei bis vier Sätze.

> „Ein möglicher Effekt ist…"
> „Das ist keine Absicht — es ist eine Mechanik."
> „Dasselbe Muster findet sich in {Feld 1} und {Feld 2}."
> „Das macht keine Aussage falsch. Es macht sie nur wirksamer."

---

## 6. Risiko-Check

| Kriterium                                                    | Antwort     |
|--------------------------------------------------------------|-------------|
| Aktualität (1–5)                                             |             |
| Psychologische Relevanz (1–5)                                |             |
| **Polit. Vereinnahmungsrisiko (1–5)**                        |             |
| Viralpotenzial (1–5)                                         |             |
| Kursnähe (1–5)                                               |             |
| Visuelle Umsetzbarkeit (1–5)                                 |             |
| **Total (siehe scoring_system.md)**                          |             |
| Stoppregel ausgelöst? (ja/nein, falls ja: welche)            |             |
| Lager-Test (Prompt 10) durchgeführt? (ja/nein, Anmerkung)    |             |
| Mindestens 2 Streuungs-Beispiele im Skript? (ja/nein)        |             |
| Konjunktiv bei Intention durchgehalten? (ja/nein)            |             |
| Verschwörungs-/Empörungssprache im Skript? (ja/nein)         |             |
| Personennamen im Skript? (ja/nein, falls ja: Begründung)     |             |
| Selbst-Empfinden: ruhig oder triggernd?                      |             |
| Cooldown nötig? (24h / 48h / nein)                           |             |

> **Regel:** Erst wenn alle Risiko-Felder ausgefüllt **und** konsistent
> mit unseren Stoppregeln sind, wird das Brief auf Status „Skript" gehoben.

---

## 7. CTA

Welcher CTA, exakt formuliert (eine Variante pro Plattform).
Niemals Hardsell.

- **TikTok/Reels/Shorts:** „{CTA}"
- **LinkedIn:** „{CTA, B2B-Ton}"
- **YouTube Description:** „{CTA + Link zu Newsletter/Lead Magnet}"

Erlaubte CTA-Familie:

- „Folge, wenn du öffentliche Kommunikation besser verstehen willst."
- „Speichere dir das, wenn du Manipulation schneller erkennen willst."
- „Mehr Mechaniken hinter Meinung im Newsletter."
- „Das vollständige System findest du im Kurs."

---

## 8. Visual Ideas

Was steht typografisch im Raum? Was wird markiert?

- **Schlüsselwort im Raum:** „{WORT}"
- **Markierungen:** {z. B. „rote Linie unter dem Verb"}
- **Spotlight-Akzent:** {Position relativ zum Host}
- **Slate / Episodenmarker:** {z. B. „FA · №. 14"}
- **B-Roll:** {Typo-Layouts, kein Stock}
- **Letzter Frame:** {ruhig, schwarze Wand, einzelnes Wort?}

Visual-Identity-Regeln (siehe `visual_identity.md`):
- Schwarz / Offwhite / Nachtblau / Eisblau / Rot nur als Markierung.
- Display-Grotesk, Akzent-Serif einmal pro Folge.
- Kein Stock, keine Pfeile, keine Emojis im Bild.

---

## 9. Schnittnotizen

- **Ziel-Dauer:** {30s | 45s | 60s | 90s | LF 8–12 min}
- **Schnittfrequenz:** Cuts auf Bedeutung, nicht auf Takt.
  Durchschnittlich 1 Cut alle 2,5–4 Sekunden.
- **Pausen-Marker:** vor dem Schlüsselwort 200–400 ms Stille.
- **Sting/„Punkt":** ein einziger, bei der Hervorhebung.
- **Score:** −18 bis −22 LUFS unter Stimme.
- **Captions:** Markierungen, keine Wiederholung des Gesprochenen.
- **Cover-Frame:** {welcher Frame, welche Hook-Variante?}
- **Plattform-Cuts:** TikTok / Reels / Shorts / LinkedIn — siehe
  `platform_adaptation_matrix.md`.

---

## 10. Pre-Flight Checklist (vor Posting)

- [ ] Hook in den ersten 1,5 Sek. (Bild + Sprache)
- [ ] Mechanik klar benannt
- [ ] Streuungs-Beispiele aus ≥ 2 Feldern (falls Risiko-Achse C ≥ 3)
- [ ] Konjunktiv bei Intention
- [ ] CTA ohne Hardsell
- [ ] Keine Lager-/Verschwörungs-Sprache
- [ ] Letzter Frame ruhig
- [ ] Safety-Lint (Prompt 8) durchgeführt
- [ ] Lager-Test (Prompt 10) durchgeführt, falls Risiko ≥ 3
- [ ] Plattform-spezifische Captions ausformuliert
- [ ] Newsletter-Verknüpfung geprüft (passt das Thema zur kommenden
      Ausgabe?)

---

## 11. Post-Flight (nach 7 Tagen ausfüllen)

- Hold @ 3s: {%}
- Completion: {%}
- Saves / View: {Verhältnis}
- Shares / View: {Verhältnis}
- Newsletter-Signups: {Anzahl}
- Kommentar-Sentiment (1–5): {Wert}
- Abweichung zur prognostizierten D (Viralpotenzial): {+/−}
- Abweichung zur prognostizierten C (Lager-Risiko): {+/−}
- Was wir gelernt haben: {1–3 Sätze}

> Die Post-Flight-Daten fließen in das Re-Scoring (siehe
> `scoring_system.md`, Abschnitt 8) und in `hook_database.md`.
```

## Beispiel-Brief (ausgefüllt)

```markdown
# Episode Brief №. 02 — „Bedauerlich"

**Status:** ☑ Idee  ☑ Brief  ☐ Skript  ☐ Dreh  ☐ Schnitt  ☐ QA  ☐ Live
**Slot:** 2026-05-19 · TikTok 18:30 · Reels 19:00 · Shorts 09:00 (Folgetag)
**Rubrik:** Framing-Alarm
**Säule:** Framing
**Owner:** Nico
**Last Reviewer:** Producer (TBD)

## 1. Thema
Die Floskel *bedauerlich* taucht regelmäßig in Pressestatements auf,
nachdem Verantwortung im Raum steht.

## 2. Hook
„Achte auf das Wort *bedauerlich*."

## 3. Mechanismus
- **Begriff:** Soft-Verb / Verantwortungs-Verschiebung
- **Definition:** Ein Wort, das Gefühl statt Handlung bezeichnet — die
  Frage nach dem *Wer hat etwas getan?* wird ersetzt durch die Frage
  nach dem *Wer findet das schade?*.

## 4. Beispiel
- Beispiel 1 (Politik, generisch): „X bezeichnet Y als *bedauerlich*."
- Beispiel 2 (Wirtschaftspresse): Pressestatement nach Produktrückruf.
- Beispiel 3 (Sport): Statement nach kontroverser Schiedsrichterszene.

## 5. Neutrale Einordnung
„Ein möglicher Effekt ist, dass das Bewusstsein vom *Wer* zum *Wie
schade* wandert. Das ist keine Absicht — es ist eine Routine der PR-
Sprache. Dieselbe Routine findet sich in Wirtschaftspresse, Sport und
Behördenkommunikation."

## 6. Risiko-Check
| Kriterium | Antwort |
|-----------|---------|
| A Aktualität | 1 |
| B Psychologische Relevanz | 5 |
| C Polit. Vereinnahmungsrisiko | 1 |
| D Viralpotenzial | 4 |
| E Kursnähe | 4 |
| F Visuelle Umsetzbarkeit | 5 |
| Total | 39 |
| Stoppregel? | nein |
| Lager-Test | nicht nötig (C = 1) |
| Streuungs-Beispiele | ja (2) |
| Konjunktiv | ja |
| Verschwörungssprache | nein |
| Personennamen | nein |
| Selbst-Empfinden | ruhig |
| Cooldown nötig? | nein |

## 7. CTA
- TikTok/Reels/Shorts: „Folge, wenn du solche Wörter schneller sehen
  willst."
- LinkedIn: „Mehr Comms-Mechaniken für Führungskräfte — Link im Profil."
- YouTube Description: „Newsletter-Link in der Beschreibung."

## 8. Visual Ideas
- Schlüsselwort im Raum: **BEDAUERLICH**
- Markierung: rote Linie unter dem Wort am Sek. 5.
- Spotlight-Akzent: leicht von hinten-oben, kühl.
- Slate: „FA · №. 02"
- B-Roll: zwei Typo-Layouts von Beispielsätzen.
- Letzter Frame: schwarze Wand, ein einzelnes „bedauerlich" klein
  oben links.

## 9. Schnittnotizen
- Dauer: 40 Sek.
- 200 ms Pause vor *bedauerlich*.
- Ein Sting beim ersten Auftauchen.
- Score: tief, nur fühlbar.
- Caption: nur Markierungen, keine Wiederholung.
- Plattform-Cuts: siehe `platform_adaptation_matrix.md`.

## 10. Pre-Flight
- [ ] Hook in 1,5 Sek.
- [ ] Mechanik klar benannt
- [ ] Streuungs-Beispiele ≥ 2 Felder
- [ ] Konjunktiv
- [ ] CTA ohne Hardsell
- [ ] Letzter Frame ruhig
- [ ] Safety-Lint
- [ ] Plattform-Captions
- [ ] Newsletter-Verknüpfung
```

## Wie das Brief im Sprint genutzt wird

- **Montag (Sprint-Kick-off):** Briefs werden in der Wochenplanung
  geöffnet.
- **Dienstag:** Briefs auf Status „Skript" hochziehen, wenn Risiko-
  Check sauber.
- **Mittwoch:** Drehblock — pro Brief Take 1–3.
- **Donnerstag:** Schnitt + QA gegen das Brief.
- **Freitag:** Posting, Brief auf „Live", Post-Flight-Eintrag
  geplant für T+7.

Ein Brief, das nicht zu Live geht, bleibt erhalten — es ist
Trainingsmaterial für den Score (Abschnitt 8 in
`scoring_system.md`).
