# Script Templates

Diese Vorlagen sind Beats, keine Zwangsjacken. Jede Vorlage benennt
Funktion, Dauer und sprachliche Bausteine. Texte sind als Platzhalter
in `{geschweiften Klammern}` markiert.

Sprecher-Regie für Nico in allen Templates:
> **Ruhig. Eine Bedeutung pro Satz. Mikro-Pause vor dem Schlüsselwort.
> Niemals laut werden. Auf dem letzten Wort nicht steigen — leicht
> abfallen lassen.**

## Template A — 30 Sekunden (Framing-Alarm)

**Zweck:** Ein Wort, eine Wirkung. Maximale Verdichtung.

```
[0:00–0:02 HOOK]
"Achte auf das Wort {SCHLÜSSELWORT}."

[0:02–0:08 KONTEXT]
"Es taucht gerade in {Quelle/Setting, generisch} auf."

[0:08–0:20 MECHANISMUS]
"Dieses Wort macht etwas, bevor du nachdenkst:
es {Frame-Wirkung in einem Satz}.
Tauschen wir es aus gegen {Alternativwort 1} — oder gegen {Alternativwort 2} —
und der Satz verschiebt sich."

[0:20–0:27 WIRKUNG]
"Du liest nicht den Sachverhalt. Du liest den Rahmen."

[0:27–0:30 TWIST + CTA]
"Das macht es nicht falsch. Es macht es wirksam.
Folge, wenn du das schneller sehen willst."
```

## Template B — 45 Sekunden (Der Satz, der dich lenken soll)

**Zweck:** Einen Satz in 3–5 Bauteile zerlegen.

```
[0:00–0:03 HOOK]
"Dieser Satz wirkt harmlos. Schauen wir mal."

[0:03–0:10 ZITAT]
"{vollständiger Satz, neutral gelesen}"

[0:10–0:35 ZERLEGUNG]
"{Wort 1} — das ist {Frame-Funktion 1}.
{Wort 2} — das ist {Frame-Funktion 2}.
{Wort 3} — das ist {Frame-Funktion 3}.
{Wort 4, optional} — das ist {Frame-Funktion 4}."

[0:35–0:42 WIRKUNG]
"Der Satz fordert dich nicht auf, zuzustimmen.
Er setzt voraus, dass du es schon tust."

[0:42–0:45 TWIST + CTA]
"Eine mögliche Funktion. Keine Anklage.
Speichere dir das, wenn du Manipulation schneller erkennen willst."
```

## Template C — 60 Sekunden (Warum das so gut funktioniert)

**Zweck:** Einen Mechanismus erklären — evergreen.

```
[0:00–0:02 HOOK]
"Warum funktioniert {MECHANISMUS} so zuverlässig?"

[0:02–0:10 DEFINITION]
"{Mechanismus} bedeutet: {alltagstaugliche Definition in einem Satz}."

[0:10–0:30 ERKLÄRUNG]
"Stell dir vor, {Alltagsbild oder Studie sehr knapp}.
Genau das passiert in deinem Kopf, wenn {Anwendungsbeispiel}."

[0:30–0:45 ANWENDUNG]
"In öffentlicher Kommunikation siehst du das hier:
{Beispiel 1, generisch} — {Beispiel 2, andere Seite}.
Dieselbe Technik, unterschiedliche Akteure."

[0:45–0:55 WIRKUNG]
"Du fühlst dich informiert, weil dir etwas vertraut wird.
Vertraut fühlt sich wahr an. Das ist die Mechanik."

[0:55–1:00 TWIST + CTA]
"Wer das einmal sieht, kann es nicht mehr nicht sehen.
Mehr Mechaniken hinter Meinung im Newsletter."
```

## Template D — 90 Sekunden (Manipulation der Woche)

**Zweck:** Aktuelle Debatte einordnen, **ohne** Lager.

```
[0:00–0:03 HOOK]
"Diese Woche eine Mechanik, die du an drei Stellen sehen konntest."

[0:03–0:15 BEOBACHTUNG]
"Es geht um {Thema, generisch beschrieben}.
Was mich nicht interessiert, ist das Lager.
Was mich interessiert, ist die Technik."

[0:15–0:50 MECHANIK]
"Die Technik heißt {Begriff}. Sie funktioniert so:
{Erklärung in zwei Sätzen}.
In dieser Woche tauchte sie auf in {Beispielfeld 1},
in {Beispielfeld 2} und in {Beispielfeld 3}.
Drei Akteursgruppen, dieselbe Technik."

[0:50–1:15 WIRKUNG]
"Bei dir entsteht der Eindruck, dass {beobachtbarer Effekt}.
Das ist nicht zwingend Absicht.
Es ist häufig Routine. Aber Routine formt Wahrnehmung."

[1:15–1:25 ENTSCHÄRFUNG]
"Das bedeutet nicht, dass die Aussage falsch ist.
Es bedeutet nur: sie ist gebaut."

[1:25–1:30 CTA]
"Wenn du solche Mechaniken systematisch lesen willst,
schau in den Lead Magnet."
```

## Template E — 90 Sekunden (LinkedIn-Variante)

**Zweck:** B2B-Anschluss, gleiche Substanz, andere Rahmung.

```

[0:03–0:15 RAHMUNG]

Aufmerksamkeit und Suggestion. Dieselben Mechaniken finden Sie
in Pressemitteilungen, All-Hands-Meetings und PR-Texten."

[0:15–0:55 MECHANIK]
"Wort eins: {Wort}. Funktion: {Funktion}.
Wort zwei: {Wort}. Funktion: {Funktion}.
Wort drei: {Wort}. Funktion: {Funktion}.
Drei Wörter, eine Architektur: {Übergreifender Mechanismus}."

[0:55–1:20 RELEVANZ FÜR FÜHRUNG]

Es entscheidet die Architektur des Satzes.
Wer diese Architektur kennt, kommuniziert klarer

[1:20–1:30 CTA]
"Für Comms-Teams gibt es das vollständige System
als Inhouse-Training. Link im Profil."
```

## Template F — Longform 8–12 Minuten („Anatomie einer Schlagzeile")

**Zweck:** Tiefe, SEO, Newsletter-Begleitung, Trust.

```
[KALTÖFFNUNG · max. 0:45]
Eine Szene. Eine Beobachtung. Ein Satz, der hängenbleibt.
Beispiel: "Eine Schlagzeile schreibt selten, was passiert ist.
Sie schreibt, wie du es lesen sollst."

[TITELKARTE]
"ANATOMIE — №. {NN}: {Schlagzeile als Display}"

[KAPITEL 1 · 1:30 LEXIKON]
- Welche Wörter wurden gewählt?
- Welche Konnotationen tragen sie?
- Welche Alternativen wurden nicht gewählt?

[KAPITEL 2 · 2:00 ARCHITEKTUR]
- Reihenfolge.
- Anker (Zahlen, Eigennamen, Orte).
- Was steht im Vordergrund, was im Nebensatz?
- Was wurde weggelassen?

[KAPITEL 3 · 2:00 WIRKUNG]
- Welcher Frame entsteht in den ersten zwei Sekunden Lesedauer?
- Welche Emotion?
- Welche Erwartung an den folgenden Text?

[KAPITEL 4 · 1:30 GEGENBEISPIELE]
- Dieselbe Mechanik in Schlagzeilen aus anderen Häusern,
  anderen Lagern, anderen Branchen.
- Pflicht-Kapitel — siehe safety_and_positioning_rules.md.

[KAPITEL 5 · 1:30 WERKZEUGE]
- Drei Lese-Werkzeuge, die das Publikum mitnimmt.
- Werkzeug 1: Wort-Austausch.
- Werkzeug 2: Reihenfolge umstellen.
- Werkzeug 3: Frage „was fehlt?".

[OUTRO · 0:45]
- Newsletter-Verweis (sanft).
- Hinweis auf nächste Folge.
- Letzter Frame ruhig.
```

## Gemeinsame Sprachbausteine („Brandsafe-Phrasen")

Verwende diese Bausteine, um eine Aussage **scharf** zu machen,
ohne **rechthaberisch** zu klingen.

- „Ein möglicher Effekt ist…"
- „Das bedeutet nicht automatisch, dass es falsch ist."
- „Das ist keine Absicht — das ist ein Mechanismus."
- „Diese Technik findet sich auf allen Seiten."
- „Beobachtbar ist…"
- „Psychologisch interessant ist…"
- „Schauen wir nüchtern."
- „Das ist kein Vorwurf — das ist eine Lesart."

Verwende **nicht**:

- „Die Wahrheit ist…"
- „Endlich sagt es jemand…"
- „Sie wollen, dass du…"
- „Skandal!"
- „Wach auf."

---

## Hook–Mechanik–CTA-Mapping

Damit ein Skript niemals leer wirkt, gilt die einfache Regel:

> Eine Hook ohne Mechanik ist Clickbait.
> Eine Mechanik ohne Twist ist eine Vorlesung.
> Ein Twist ohne CTA ist eine vergebene Chance.

Jedes Skript muss alle drei Elemente klar markieren.
